## 🚀 ویژگی‌های کلیدی سیستم (Features)

### ۱. رابط کاربری و تجربه مشتری (Frontend & UX)
- **پشتیبانی کامل از تم روشن و تاریک (Dark/Light Mode)** با حفظ سلیقه کاربر.
- **تایپوگرافی استاندارد فارسی** با فونت وزیرمتن (Vazirmatn) و ساختار کاملاً راست‌چین (RTL).
- **نرمال‌سازی ارقام فارسی/عربی:** تبدیل خودکار اعداد به انگلیسی در فرم‌های شماره موبایل، کد پستی، پسورد و قیمت‌ها.
- **پورتال سراسری مدال‌ها (`createPortal`):** جلوگیری قطعی از بریده شدن یا هم‌پوشانی مدال‌ها با هدرهای چسبان همراه با قفل خودکار اسکرول صفحه.
- **کاتالوگ جامع کالاها:** فیلتر آنی بر اساس دسته‌بندی، برند، محدوده قیمت، موجودی انبار و مرتب‌سازی‌های متنوع.
- **سبد خرید و تسویه‌حساب چندمرحله‌ای:** محاسبه آنی هزینه ارسال (ارسال رایگان بالای ۲ میلیون تومان)، تخفیف‌ها و کوپن.
- **پروفایل کاربری جامع:** مدیریت دفترچه آدرس‌ها (تعیین آدرس پیش‌فرض به صورت اتمیک)، تغییر کلمه عبور، تاریخچه و وضعیت سفارشات.
- **سیستم نقد، بررسی و امتیازدهی:** ثبت نظرات کاربران، امتیازدهی ۵ ستاره و شمارنده لایک/دیس‌لایک.

### ۲. معماری بک‌اند و امنیت (Backend & Security)
- **انبارداری اتمیک و ضد بیش‌فروشی (Anti-Overselling):** مدیریت موجودی کالا در تراکنش‌های همزمان SQLite جهت پیشگیری از منفی شدن انبار.
- **ایزوله‌سازی دسترسی کاربران (Tenant Isolation):** هر کاربر منحصراً به فاکتورها و آدرس‌های متعلق به خود دسترسی دارد.
- **احراز هویت و کنترل دسترسی (RBAC & JWT):** محافظت سخت‌گیرانه با خطای ۴۰۳ از تمام اندپوینت‌های ادمین و هشینگ امن کلمه عبور با bcrypt.
- **لغو سفارش با بازگردانی موجودی:** قابلیت بازگشت خودکار اقلام لغو شده به انبار.
- **موتور محاسبه کوپن:** اعتبارسنجی مبالغ درصدی و ثابت، رعایت کف حداقل خرید و جلوگیری از منفی شدن فاکتور.

### ۳. پنل مدیریت یکپارچه (Admin Panel)
- **داشبورد و آمار:** درآمد کل، تعداد سفارشات، تعداد کاربران و موجودی انبار.
- **مدیریت محصولات:** ایجاد، ویرایش، حذف آبشاری ایمن (Cascade Delete) و مدیریت دقیق موجودی عددی (`stockQuantity`).
- **مدیریت سفارشات:** تغییر وضعیت سفارش (`pending_payment`, `processing`, `shipped`, `delivered`, `cancelled`) و مشاهده مشخصات خریدار.
- **مدیریت کدهای تخفیف:** ایجاد کوپن‌های درصدی یا ثابت با تعیین حداقل خرید و وضعیت فعال/غیرفعال.

## 🛠️ استک فنی (Tech Stack)

### فرانت‌اند:
- **Core:** React 19 + TypeScript
- **Bundler & Build Tool:** Vite 8
- **Styling:** TailwindCSS v4
- **Routing:** React Router v7
- **Motion & Icons:** Motion (Framer Motion 12) + Lucide React

### بک‌اند و دیتابیس:
- **Server:** Node.js 22 + Express 5
- **Database:** SQLite (Better-SQLite3) در حالت WAL Mode
- **ORM:** Drizzle ORM
- **Validation:** Zod Schemas
- **Security:** Helmet, Express Rate Limit, JWT, Bcrypt

### تست و کیفیت‌سنجی:
- **Framework:** Vitest 4 + Supertest 7
- **آمار تست‌ها:** **۳۵۳ تست خودکار فعال در ۴۸ فایل تست** (۱۰۰٪ پاس شده 🟢)

### استقرار و DevOps:
- **کانتینرسازی:** Docker (Multi-stage build) + Docker Compose
- **وب‌سرور و Reverse Proxy:** Nginx با فشرده‌سازی خودکار Gzip
- **گواهینامه امنیتی:** Let's Encrypt SSL (HTTPS) با تمدید خودکار Certbot
- **سیستم‌عامل سرور:** Ubuntu 24.04 LTS

## 📁 ساختار پروژه (Project Structure)

```text
Janebi-Store/
├── server/                   # کدهای بک‌اند
│   ├── data/                 # داده‌های اولیه و بذر دیتابیس (Seed)
│   ├── db/                   # کانفیگ دیتابیس Drizzle و اسکیمای جداول
│   ├── middleware/           # میدل‌ورهای احراز هویت، اعتبارسنجی و مدیریت خطا
│   ├── routes/               # اندپوینت‌های API (admin, auth, cart, orders, products, ...)
│   ├── validators/           # اسکیمای اعتبارسنجی Zod
│   ├── app.ts                # پیکربندی اکسپرس و میدل‌ورها
│   ├── env.ts                # اعتبارسنجی متغیرهای محیطی
│   └── index.ts              # نقطه ورود سرور، استقرار استاتیک و مقداردهی خودکار دیتابیس
├── src/                      # کدهای فرانت‌اند React
│   ├── components/           # کامپوننت‌های عمومی و ماژولار (Admin, Cart, Checkout, Profile, ...)
│   ├── contexts/             # مدیریت استیت سراسری (Auth, Cart, Wishlist, Compare, Theme)
│   ├── hooks/                # هوک‌های اختصاصی (useCartSummary, useCheckoutForm, ...)
│   ├── lib/                  # توابع کمکی، تبدیل تاریخ و اعداد فارسی
│   ├── pages/                # صفحات اپلیکیشن و پنل ادمین
│   └── main.tsx              # نقطه ورود کلاینت
├── tests/                    # مجموعه تست‌های جامع (۳۵۳ تست در ۴۸ سوئیت)
│   ├── api/                  # تست‌های اندپوینت‌های بک‌اند و امنیت
│   ├── concurrency/          # استرس تست‌های همزمانی و شرایط رقابتی انبار
│   ├── postgres/             # تست‌های اعتبارسنجی پاریتی پستگرس
│   └── unit/                 # تست‌های واحد توابع فارسی، فرمت‌ها و Rollback دیتابیس
├── docker-compose.yml        # تنظیمات اجرای سرویس‌ها در داکر
├── Dockerfile                # دستورالعمل بیلد بهینه ایمیج داکر
└── vite.config.ts            # تنظیمات ساخت فرانت‌اند
```

## ⚙️ راهنمای اجرای محلی (Local Development)

```bash
# ۱. کلون کردن مخزن
git clone https://github.com/Bnan7441/Janebi-Store.git
cd Janebi-Store

# ۲. نصب وابستگی‌ها
npm install

# ۳. کپی متغیرهای محیطی
cp .env.example .env

# ۴. اجرای سرور توسعه (همراه با HMR)
npm run dev

# ۵. اجرای تمامی ۳۵۳ تست خودکار
npm test

# ۶. بیلد پروداکشن
npm run build
```
